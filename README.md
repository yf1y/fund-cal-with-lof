# 基金实时估值监控系统

这是一个极简的网页版基金实时盘中估值监控工具。用户输入 6 位基金代码后，系统会自动拉取该基金最新披露的十大重仓股及其权重比例，并结合腾讯财经的实时股票行情，加权计算出基金实时的盘中预估涨跌幅。

> **适用场景说明**
> 当前由于监管原因，绝大部分炒股和基金代销软件已下线真实的公募基金盘中净值估算功能。此工具可作为基民大致了解持仓实况的参考。
> **注意**：由于只能获取上个季度的“十大重仓股”（非全盘股票），存在“未知仓位”及基金经理调仓等天然数据滞后与截断，因此估值必定存在误差。系统前端会提示“未知仓位”比例，以辅助判断估算的潜在误差范围。

## 🛠️ 项目架构

项目采用纯前后端分离的方案开发，但为了方便本地一键启动体验和零门槛部署，后端直接通过 FastAPI 服务挂载了前端静态网页文件。这意味着只需启动一个独立服务（默认端口 8000），即可完整运行本系统。

### Backend (后端代码)
对应目录：`/backend/`
- **基础框架**：Python 3.x + FastAPI + Uvicorn
- **核心组件**：
  - `akshare`：无需 Token 和账号，直接从互联网（如东财）免费抓取基金的基础信息和历史季度重仓股数据。
  - `httpx`：提供异步网络请求支持，高并发向腾讯财经批量拉取股票秒级行情。
- **核心文件说明**：
  - `main.py`：后端的业务主干与路由。包含获取持仓数据、加权计算算法推算、简单的内存字典缓存以及静态前端网页的代理挂载。
  - `requirements.txt`：项目运行所需的 Python 依赖列表。

### Frontend (前端代码)
对应目录：`/frontend/`
- **基础框架**：原生 HTML + JavaScript (无重度前端框架，极其轻量)
- **核心文件说明**：
  - `index.html`：包含所有的页面结构、样式与交互访问逻辑。它主要负责：
    - 时钟走秒与时间的实时渲染。
    - 利用 `setInterval` 每 10 秒向后端发起轮询，刷新已关注基金池的最新估值数据。
    - 基于符合中国股市习惯的涨跌视觉交互（红涨绿跌）。
    - 本地浏览器缓存（Local Storage）记忆用户添加的基金代码。
    - 显示该基的“未知仓位”占比警示。

### 部署与拓展脚本
- `share.py`：辅助脚本。利用 `pyngrok` 将本地服务端口映射并穿透到公网，方便用户用手机或其他外部网络环境设备直接访问本地运行的服务。
- `render.yaml`：云平台 Render 的部署描述文件 (Blueprint) ，支持免费的一键化云端部署。

## 🚀 本地运行方式

请确保你的电脑上已经安装好 **Python 3** 环境。

**1. 创建并激活虚拟环境**
在项目根目录打开终端（以 Windows PowerShell 为例，Linux/macOS 略去 `Scripts\` 等路径变更）：
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**2. 安装项目依赖**
```powershell
pip install -r backend\requirements.txt
```

**3. 启动项目服务端主程序**
```powershell
python backend\main.py
```
> 服务启动完成后，**在本机浏览器**中输入以下地址即可开始使用：
> 👉 [http://127.0.0.1:8000](http://127.0.0.1:8000)

**4. 进阶：如何将服务通过公网分享给他人（或自己手机端访问）**
如果你希望在户外用手机查看，或者分享给朋友看，请保持上一步的 `main.py` 运行窗口不关闭。重新打开一个新的终端窗口，激活虚拟环境并执行：
```powershell
python share.py
```
这会启动 ngrok 内网穿透服务，然后在终端里生成一个 `https://xxxx.ngrok-free.app` 形式的临时**公网链接**。任何人在手机或电脑浏览器中打开此公网链接即可访问！
> **首次运行提示**：如果未配置 ngrok 认证令牌，此脚本运行时会提示你前往 ngrok 官网免费注册，并提供一条带状的 `Authtoken`。填写配置后即可永久使用。

## ☁️ 线上云端部署 (Render 免费部署)

本项目在根目录提供有 `render.yaml` 文件，如果你希望将服务24小时一直跑在云端而不是自己电脑上，项目原生支持通过 [Render](https://render.com/) 云平台一键完成免费部署方案。

1. Fork 本项目，或者将当前项目的全部代码同步推送到你的个人 GitHub 仓库中。
2. 登录 [Render Dashboard](https://dashboard.render.com/)，选择新建资源并点击 **"Blueprint"**，或者直接建一个 **"Web Service"**。
3. 关联、赋予权限并选择你的 GitHub 仓库目标项目。Render 会自动读取并识别根目录下的 `render.yaml` 配置文件。
4. 随后配置系统会自动执行依赖安装 (`pip install -r backend/requirements.txt`) 和启动命令 (`uvicorn backend.main:app --host 0.0.0.0 --port $PORT`)。
5. 部署过程完成后，你将在 Render 上获得一个长久有效的免费公网地址。
