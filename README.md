# 基金实时估值监控系统

网页版的极简基金实时监控，用户输入基金代码，系统通过读取该基金最新披露的十大重仓股及其占比权重，结合从腾讯财经获取的股票盘中实时涨跌幅，计算出实时的盘中净值推算涨跌幅。

## 适用场景
由于监管原因，很多炒股软件不再提供公募基金盘中净值估算。该工具专为需要大致了解自己持仓基金盘中表现的基民提供。注意：存在“未知仓位”及基金经理调仓等天然误差。

## 项目架构

项目采用了纯前后端分离的方案，但为了本地环境体验和零部署直接单服务拉起，利用了 FastAPI 来托管静态网页，即在一个端口（8000）下解决所有服务。

### Backend (后端)
**目录：** `/backend/`
- **框架：** Python 3.x + FastAPI + Uvicorn
- **核心库：** 
  - `akshare`：无需各种 Token，零成本从互联网抓取东财的基金历史季度持仓及基金基础信息。
  - `httpx`：提供异步网络请求，高并发向腾讯财经批量拉取股票秒级行情。
- **文件说明：**
  - `main.py`：后端所有业务与路由。包含了拉取持仓、加权算法推算、缓存（内存字典）和静态网页代理。
  - `requirements.txt`：项目依赖列表。

### Frontend (前端)
**目录：** `/frontend/`
- **框架：** HTML + JavaScript 原生实现
- **文件说明：**
  - `index.html`：包含页面结构与交互逻辑。它负责：
    - 时钟走秒渲染；
    - `setInterval` 每 10 秒向后端轮询已添加的基金数据；
    - 基于中国股市审美的涨跌幅变色（红涨绿跌）；
    - 显示该基的**估值误差（未知仓位占比占比越高，往往误差越大）**。

## 运行方式
确保电脑已安装 Python。
1. 在项目根目录创建并激活虚拟环境：
   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```
2. 安装依赖：
   ```powershell
   pip install -r backend\requirements.txt
   ```
3. 启动并访问主程序：
   ```powershell
   python backend\main.py
   ```
   启动后，**本地电脑只有你自己**可以访问以下地址使用：
   [http://127.0.0.1:8000](http://127.0.0.1:8000)

4. **让其他人（外网或手机）访问（生成公有网站地址）**：
   当你需要将系统分享给不在同一网络下的手机或朋友时，请**保持**前一步的 `python backend\main.py` 窗口不要关闭。
   新开一个终端窗口（Powershell），同样激活虚拟环境并执行：
   ```powershell
   python share.py
   ```
   这会启动 `ngrok` 内网穿透服务，生成一个以 `https://xxxx.ngrok-free.app` 形式显示的**公网链接**。你和其他人只要在手机或电脑浏览器中打开此公网链接即可！
   **注意**：如果是首次运行 `share.py`，如果没有 ngrok 账号，需要根据终端里的提示去官网注册并填写 `Authtoken`。
